# 빨간 벽 허물기 수업 (장애인식개선 수업용 웹앱)

학생들이 로그인 없이, 같은 와이파이에서 주소만 열면 함께 쓰는 수업용 웹앱입니다.
쌓은 벽돌, 이모티콘 작품, 다짐 이름이 모든 기기에 바로 공유됩니다.

## 켜는 방법

1. 교사 컴퓨터에 Node.js 18 이상을 설치합니다. (https://nodejs.org 에서 LTS 버전)
2. 이 폴더에서 아래 중 하나로 서버를 켭니다.
   - Windows: `start.bat` 더블클릭
   - Mac: 터미널에서 `bash start.sh`
   - 직접: 터미널에서 `node server.js`
3. 화면에 나오는 주소를 확인합니다.
   - 교사 컴퓨터: `http://localhost:3000`
   - 학생 기기: `http://192.168.x.x:3000` (화면에 나오는 "학생 기기에서" 주소. 같은 와이파이여야 해요.)
4. 열자마자 기본 반 코드 `우리반`으로 자동 연결돼요. 반을 나누려면 위쪽 `공유` 버튼에서 반 코드(예: 5-1)와 이름을 입력해 연결하세요.

## 인터넷 주소로 배포하려면

`DEPLOY.md`를 따라 하세요. (Render 무료 서버, 교사 PIN 보호 포함)

## 알아 둘 점

- 데이터는 이 폴더의 `data.json`에 저장됩니다. 서버를 껐다 켜도 남아 있어요.
- 반 코드가 다르면 데이터가 따로 저장됩니다. 한 서버로 여러 반이 함께 쓸 수 있어요.
- 교사용 서랍(오른쪽 위 `교사용`)의 `활동 결과 지우기`는 지금 연결된 반 코드의 데이터를 지웁니다.
- 학교 와이파이가 기기끼리의 접속을 막으면 학생 기기에서 열리지 않을 수 있어요. 그때는 교사 컴퓨터에서 핫스팟을 켜고 연결해 보세요.
- 포트를 바꾸려면 `PORT=8080 node server.js` (Windows는 `set PORT=8080` 후 실행)
- 인터넷에 올려서 쓰려면 Node.js 서버를 지원하는 호스팅(Render, Railway 등)에 이 폴더를 올리고 시작 명령을 `node server.js`로 지정하세요. 로그인이나 접근 제한이 없으니 주소를 아는 사람은 누구나 쓸 수 있어요. 호스팅에 따라 `data.json`이 재시작 때 사라질 수 있습니다.

## 파일

- `DEPLOY.md` 인터넷 배포 안내
- `render.yaml` Render 배포 설정
- `server.js` 서버(외부 패키지 없음)
- `public/index.html` 수업 화면 전체
- `data.json` 첫 실행 뒤 자동으로 생기는 저장 파일
